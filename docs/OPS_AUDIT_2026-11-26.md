(Sheet ✅, SPL 19583 ✅, test league ✅, 96 emails left), Pages up, CI green, every GitHub run since the repo was created (11/25 19:19 ET).

## Verdict
The architecture is sound for a 12-owner league: static app on Pages, one Apps Script backend that hot-loads from `main` with a
last-good fallback, gold CSVs with one robot owner each, derived data rebuilt by robots, CI on every push. **The gap was the robots'
clock and anyone watching it.** Fixed in v0.16 / backend v0.12.0; three one-time steps are Mike's (below).

## Mike: three one-time steps (≈10 min, all in the runbook)
1. **`GH_TOKEN`** Script property: fine-grained token, repo `spl-hq.github.io` only, **Actions: Read and write**, 1 year (§2). Without it the
   watchdog can see nothing and run nothing; the desk shows it gold and ops gets one email asking for it.
2. **Hourly trigger** on `tick` (Apps Script → ⏰ Triggers, §4b). Until then the watchdog rides health pings, so it still runs whenever
   the app is opened or UptimeRobot pings.
3. **UptimeRobot** on `?action=health` (§5): the only watcher outside Google, for "the backend itself is down".

Also before Joe: ESPN writes are **ON** right now (test league only, from WS5 setup). Leave on for the demo, off after.

## Watch list (fine today, revisit when…)
- **`index.html` is 229 KB** in one file (~68 KB gzipped, + 32 KB league data). Fine on phones; consider splitting screens into files past ~350 KB (structural: Mike's call).
- **Loader last-good is 6 h** (CacheService max): a GitHub raw outage longer than that takes the backend down. Rare; UptimeRobot would say so.
- **Apps Script quotas** (consumer account): 100 emails/day shared by owner notifications, ops alerts and the backup; 20k URL fetches/day;
  30 simultaneous runs. Comfortable at 12 owners; the desk shows emails left.
- **Public health endpoint** lists tab names and the signed-up count. Harmless; no contacts, no tokens.
- **Two chats pushing to `main` at once** collide (happened twice 11/26). One build chat at a time, or "PR first" in the second.
- **Bus factor**: Joe as second `spl-hq` org owner after the demo; recovery phone/email on `spl.hq.ops@gmail.com`.
- GitHub disables schedules after 60 days without commits: robots commit daily, so not a risk while the watchdog/ledger run.
